# Bjuss (Familjebjuss)

En hyperlokal app där småbarnsföräldrar bjussar bort utväxta barnkläder, leksaker och annat till grannar.
Inga pengar, inget byte – allt sker till fots.

> Fullständig guide för att komma igång (Supabase, Vercel, felmeddelanden) kommer i den här filen.

## Snabböversikt

- `src/` – själva appen (React + TypeScript + Tailwind)
- `supabase/migrations/` – databasen: tabeller, säkerhetsregler och funktioner
- `supabase/tests/` – automatiska tester av databasens säkerhetsregler
- `e2e/` – automatiska tester som klickar runt i appen
- `scripts/local/` – lokal test-Supabase för utvecklare
